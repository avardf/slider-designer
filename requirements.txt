# Slider Designer — pinned Python dependencies

# The recommended way to run this app is uv, which reads pyproject.toml and
# uv.lock directly and needs none of this file:
#
#     uv run streamlit run app.py
#
# This file is for environments where uv is not an option (a locked-down
# machine, an internal mirror that only speaks pip, an existing shared venv).
# Versions are exported from uv.lock, so they are exactly the ones the app was
# built and tested against.
#
#     python -m venv .venv
#     # Windows:      .venv\Scripts\activate
#     # macOS/Linux:  source .venv/bin/activate
#     pip install -r requirements.txt
#     streamlit run app.py
#
# REQUIRES PYTHON 3.12 OR NEWER. Check with `python3 --version` first. macOS
# ships an older Python (3.9), and on that version pip fails with a misleading
# message — "Could not find a version that satisfies the requirement
# altair==..." — rather than saying your Python is too old. If you see that,
# the fix is a newer Python, not a different package version.
#
# matplotlib is deliberately absent — it is only needed by the frozen fallback
# app_matplotlib.bak.py, not by the app itself. Install it separately if you
# want to run that file.
#
# To regenerate after changing dependencies:
#
#     uv export --format requirements-txt --no-hashes --no-dev --no-emit-project -o requirements.txt
